# EXP128：通用CC列边界及行输入改进

用户已确认：先实施已有离线证据支持的两项改动，尚未定因的退化只记录和复测；范围改为偶数N≥65536；二次幂继续走通用CC，不优先切回旧专用实现。沿用双精度、一维、批量一、非原位、默认计划。

## 实际改动

1. 折叠列的加载有效性判断、首末边界及内部列写出判断移到原生寄存器遍历外，保留`pass_io`尾部保护、寄存器清零、边界缓存及同步位置。没有新增共享存储、同步或全局读写。
2. 折叠列按双精度、末级基数≥4、实际相位查表阶数≥2使用已有相位递推，不按N或列长名单选择。实际阶数由运行时生成入口传给列适配器；包括新增64K可能使用的两阶配置。普通内核和旧角色保留原来的选择条件。递推减少独立多阶查询，但增加复数推进依赖及舍入累积，收益需设备实测。
3. 正变换折叠频谱行按原生首级映射能力选择寄存器输入：因子乘积等于Q、线程及工作组非零、工作组由完整线程组组成。原生`pass_io`允许非二次幂及最后部分蝶形，不要求每变换线程数整除Q。仍保留`row<C`尾行保护，共享存储备用实现及全部输出写法。逆变换输入配对条件未放宽。
4. 通用CC门槛由N＞65536改为N≥65536，原二次幂专用入口优先级不变。65536默认分解128×256，正式清单新增双向两项；193个旧尺寸和分解表全部保留。运行时内核名统一升级为`cc_local_v2`，避免复用旧生成缓存。

实现涉及`library/src`下的`tree_node_real.cpp`、`rtc_stockham_kernel.cpp`、`rtc_stockham_gen.cpp`、`include/real_block_io.h`、`device/generator/stockham_gen_cc.h`及`stockham_gen_cc_real_columns.h`。没有引入EXP126／127的融合实现或改分解以避开慢尺寸。

覆盖表审计为194个公开尺寸、388个双向组合、283种合法原生几何。新增的4种内部几何来自64K下界纳入，不用于强制计划性能测量。

构建、独立验证和性能为三个任务。验证先跑65536、69938双向烟测，失败立即退出；之后其余代表独立用例全部运行并汇总错误。只验原包默认数值和实际两个通用融合内核，正变换行须实际选择寄存器输入。复用追踪进程的数值检查与计划／生成日志，避免重复运行同一参考。回调、非单位缩放及完整内存发布回归不属于本轮日常性能门槛。
