# EXP128：从EXP125重做CC前后处理融合——后处理方案

2026年10月21日，续10月20日的核对。范围为一维、双精度、批量一、非原位、连续输入输出、偶数 `N>65536`，复数主体采用两段矩阵路径（CC）。本轮建立分支并完成方案论证，没有修改快速傅里叶变换（FFT）生产源码，没有提交设备构建、正确性或性能任务。

## 结论

推荐后处理采用：**首段按列完成局部实数后处理；末段普通行乘相位、变换、折叠写出；两个局部端点共用一行，再用一次局部实数变换恢复。**

前处理仍沿用刚才的“折叠列变换＋中间端点打包＋SBRC行内前处理”。两个方向共享成对公式、坐标工具和资源描述，但端点数据含义不同，不能强行共用一段入口代码。后处理的主要局部配对位于SBCC末尾，末段SBRC另有一行端点恢复；这与前处理位于SBRC入口并不矛盾。

新后处理保持原来的两段复数变换长度、变换数量、工作组几何以及 `C×Q` 中间矩阵；不需要镜像行同块，不要求每块行槽为偶数，也不增加一行复数变换。成立的代价是首段增加列内交换、改变输入打包和末段相位位置，不能据此承诺所有类型提速。

数学、地址与最小读取编译证据支持实施候选。完整生成代码的寄存器分配、共享存储等待、数值误差及实际性能仍须设备验证。

## 二、数学布局和两段计算

令 `M=N/2=C×Q`。C为SBCC的复数变换长度，Q为SBRC的复数变换长度。输入实数为 `x[0…N-1]`，输出半谱为 `H[0…M]`。以下采用正向变换的负相位约定。

### 1. 首段：改变实数配对，在列内做后处理

每列编号 `b∈[0,Q)`，列内编号 `p∈[0,C)`：

```text
z_b[p] = x[b + 2Qp] + i·x[b + Q(2p+1)]
F[a,b] = C点复数正向变换(z_b)[a]
```

这正是长度 `2C` 的局部实数序列 `x[b+Qt]` 的常规复数打包。与原来配相邻实数不同，这里配相隔Q的两个实数；没有改用完整N点复数变换。所有N个实数各读取一次，输入回调也各调用一次。

对 `1≤a<C`，将 `F[a,b]` 与 `F[C-a,b]` 按现有实数后处理公式组合，得到该局部实数变换的频点 `V_b[a]`。中间结果为：

```text
T[a·Q+b] = V_b[a]       1≤a<C
T[b]     = F[0,b]       a=0，保留原始打包值
```

局部零频和局部奈奎斯特频点暂不分开。`F[0,b].real=e_b` 为局部偶数位置之和，`F[0,b].imag=o_b` 为局部奇数位置之和；一个复数槽保留这两个实数，矩阵仍为 `C×Q`。

首段不再执行原来的周期M大相位。其普通FFT核心的 `large1D` 关闭，局部后处理只需周期 `2C` 的小表。

### 2. 末段普通行：先乘周期N相位，再折叠输出

对 `a∈[1,C)`：

```text
U[a,b] = T[a·Q+b] · exp(-2πi·a·b/N)
G[a,h] = Q点复数正向变换(U[a,:])[h]
k      = 2C·h+a
```

`G[a,h]` 就是完整实数频谱的第k点。写半谱时：

```text
若 k≤M：H[k]   = G[a,h]
若 k>M：H[N-k] = conj(G[a,h])
```

共轭必须在输出回调之前完成。该步骤仅按最终物理频点调用一次回调，不先对上半谱回调后再共轭。

原来的相位位于首段FFT之后，周期M；新相位位于末段FFT之前，周期N。不能只换周期、保留原位置，更不能两处都乘。

### 3. 末段端点行：一次Q点复数FFT恢复两类端点

最直观的处理需要分别变换 `e_b+o_b` 和 `(e_b-o_b)·exp(-πi·b/Q)`，会形成 `C+1` 行Q点变换。这里可以进一步合并。

构造长度 `2Q` 的实数序列：

```text
u[b]   = e_b
u[b+Q] = o_b             0≤b<Q
H[C·t] = 2Q点实数正向变换(u)[t]    0≤t≤Q
```

该实数变换仍由**一次Q点复数FFT＋局部后处理**实现，恰好占原来 `a=0` 的行槽：

```text
terminal_input[j] = u[2j] + i·u[2j+1]
```

从打包行T读取实数分量，不建立额外全局数组：

```text
read_u(t):
    high = (t>=Q)
    b    = t-high·Q
    return T[b]的第high个实数分量
```

`t<2Q`，所以一次比较和减法即可，无需运行时除法。Q为奇数时，中间一对跨过两半的分界；上述公式自然覆盖，不假设Q为偶数。

末段完成普通Q点FFT后，沿用已有完整复数共享存储出口，在第一个工作组内把端点行分配给全组线程，读取 `j` 与 `Q-j`，局部后处理后直接写 `H[C·t]`。其余普通行照常折叠输出。后处理不回写共享存储，因此可复用已有末次同步，无需再建一个共享结果区或增加工作组。

### 4. 正确性的核心依据

完整分解为：

`X[a+2Ch]=Σ_b V_b[a]·exp(-2πi·a·b/N)·exp(-2πi·b·h/Q)`。

普通行覆盖局部余数 `a=1…C-1`。它们的共轭对应余数 `2C-a`，不在普通行集合内，因此折叠后不会与另一普通行重复。端点行覆盖所有C的倍数，与普通行不相交。写出数为：

`(C-1)Q+(Q+1)=M+1`。

端点合并来自 `FFT_real_2Q([e,o])`：偶数编号频点给出 `e+o` 的Q点变换，奇数编号频点给出带半格相位的 `e-o` 的Q点变换。因此不是把两个任意复数变换强行压成一个。

局部成对公式复用 `real_post_pair`。长度为L的打包FFT，令 `p=F[j]`、`q=F[L-j]`、`w=exp(-πi·j/L)`：

```text
ux=(p.real+q.real)/2       uy=(p.imag+q.imag)/2
vx=(p.real-q.real)/2       vy=(p.imag-q.imag)/2
A =vx·w.imag+uy·w.real     B=uy·w.imag-vx·w.real
own  ={ux+A, vy+B}
other={ux-A, B-vy}
```

首段保留原始打包零频；末段端点行才展开零频与奈奎斯特频点，分别为 `R[0].real±R[0].imag`。两者虚部在输出回调之前设为零。L为偶数时单独处理 `L/2`，结果为其共轭；L为奇数时没有这一自配对点。按下标j直接查表时，小表长度取 `ceil(L/2)`，不能沿用整数除法截断。

## 三、共享存储与寄存器：关键实施取舍

已核对EXP125登记的33种SBCC配置和21种SBRC配置。按现有SBCC交错线程映射，**没有一种列长度能把全部镜像配对都限制在同一个64线程束内**。部分配对可以在寄存器或线程束内完成，但不能因此把整类后处理写成纯寄存器交换。

首段使用列内共享交换，不为配对改变每块变换数、因子顺序或线程排列。普通核心采用完整复数共享存储时，直接复用该空间；普通核心采用半容量共享存储时，优先采用实部、虚部分两轮交换，避免为了边界配对扩大核心资源。

| 列长度C | 每块列槽 | 普通核心共享存储，字节 | 完整复数后处理交换峰值，字节 | 分两轮标量交换峰值，字节 |
|---:|---:|---:|---:|---:|
| 100 | 8 | 6400 | 12800 | 6400 |
| 168 | 6 | 8064 | 16128 | 8064 |
| 256 | 8 | 16384 | 32768 | 16384 |
| 512 | 4 | 16384 | 32768 | 16384 |
| 1024 | 4 | 32768 | 65536 | 32768 |

这五项由原配置 `half_lds` 导出，不按具体N列名单。表中是数据交换容量，不是实测占用率；调用回调所要求的额外空间仍应按现有规则核算。其余列类复用完整复数空间，全部目录的完整交换峰值为65536字节，按上述策略峰值为32768字节。

分两轮交换的关键顺序如下。所有线程都经过同步，尾块仅屏蔽有效数据的读取和写出：

```text
同步：保护尚未完成的核心共享读取
按末轮坐标写出所有最终寄存器的实部
同步
配对拥有者读取两侧实部，暂存到小型静态寄存器数组
同步：确认所有实部读取结束
按相同坐标写出虚部
同步
配对拥有者读取虚部，完成公式并写出中间矩阵
```

与一次完整复数发布相比，通常增加两次工作组同步，并需要暂存实部。复用空间意味着容量取阶段峰值，不能把两轮标量数组相加，也不能漏掉核心结束时保护旧共享读取的同步。

实现时按静态成对坐标展开，先使旧实部寄存器结束使用，再保留待组合的实部；虚部读取后立即计算写出。旋转因子按当前配对读取，不把整组相位同时保留到FFT寄存器仍活跃的阶段。最终是否减少寄存器峰值、是否出现溢出，只能由实际生成内核确认。

末段端点行虽只在首块执行，其分支仍属于同一内核，可能提高所有工作组的静态寄存器分配。应让普通输出临时变量先结束使用，再做端点行后处理，不能以“只有一块执行”推断全局没有资源代价。

## 四、读取、相位与写出的具体组织

1. **首段读取。** 使用两次有类型的8字节实数读取，分别访问 `b+2Qp` 和 `b+Q(2p+1)`。相邻列槽对应相邻b，两条读取流各自连续；指令数与原16字节复数读取不同，实际事务仍需检查。已有把复数下标直接改为相邻两个实数的访问器不能原样套用。
2. **末段普通行读取。** 读取中间复数后，在首轮蝶形前乘周期N相位。显式增加末段边界相位参数，复用既有压缩查表公式和表缓存；普通SBRC目前没有这项入口相位参数，仅设置 `large1D` 不会自动实现它。优先短距离预取当前所需相位，避免整组相位长时间占寄存器。
3. **末段端点行读取。** 以标量指针从T读取两个所需分量，再组成Q点FFT的输入。不要分别读取两个完整复数后各丢一半，也不要先生成一个全局端点数组。对奇偶Q的最小编译原型均产生两条8字节全局读取和一条16字节写出，没有整数除法或间接调用；这仅证明访问写法可编译，未证明完整内核性能。
4. **末段输出。** 普通行复用原SBRC末次共享存储转置，只修改最终物理下标和共轭；端点行在同一出口另行分配配对工作。所有输出保留 `StoreGlobal` 语法树节点，使缩放、回调及非原位访问转换继续统一生效。折叠后的不同片段可能改变写事务合并，逻辑字节相同不代表物理事务相同。
5. **相位表。** 首段小表周期 `2C`，末段端点小表周期 `2Q`，末段普通行大表周期N。表在计划准备阶段生成，通过既有缓存管理引用和释放，不在每次变换中生成。大表基数与步数按新角色局部选择，N大于 `2^18` 时使用既有基数8的合法压缩方式，避免EXP125小基数三步接口的上限；不顺手修改无关复数路径的策略。

端点行的逻辑读取共 `2Q` 个实数分量，每个恰好一次，但其8字节步长访问可能浪费部分事务字节。Q行本身较小，缓存能否抵消这一影响属于性能问题，不把逻辑读取模型当作缓存命中证明。

## 五、预计减少什么，额外付出什么

对照为两段普通 `N/2` 复数FFT＋独立后处理，不含计划准备。双精度复数16字节：

| 项目 | 新方案相对未融合对照 |
|---|---|
| 复数FFT长度及数量 | 不变：Q次C点、C次Q点 |
| 变换内核启动 | 3次变为2次 |
| 中间矩阵 | 仍为M个复数，即16M字节 |
| 逻辑全局数据搬运 | 减少独立后处理引起的16M字节读取及16M字节前序写出，合计32M＝16N字节 |
| 首段后处理交换 | 上界约32M字节共享存储读写，另有同步与成对计算 |
| 半容量核心的交换 | 容量保持原值，增加同步和实部暂存 |
| 末段端点恢复 | 局部后处理规模为Q；不增加一次Q点复数FFT，不增加共享存储容量 |
| 输入及输出事务 | 首段两条标量读取流，末段折叠写出；事务合并和依赖需要实测 |
| 大相位依赖 | 从首段FFT之后移到末段首轮蝶形之前，可能成为新的等待来源 |
| 准备阶段 | 小表、边界相位描述及生成代码增加；不计入稳定执行事件时间 |

局部成对计算是把原全局后处理重新分布，不能把全部局部计算都算作净新增，也不能把所有省下的全局字节按设备峰值带宽直接换成提速百分比。相对EXP127已有末段配对后处理，新方案还引入首段列内交换，未必更快；选择依据是去除跨行配对限制、保留普通几何，而不是已取得性能优势。

## 六、淘汰或保留为对照的其他方式

| 方式 | 判断 |
|---|---|
| 在现有SBRC末尾继续全局镜像行配对 | 保持原算法，但镜像行同块、偶数槽、尾块及共享资源的耦合仍在，不作为本轮主方案 |
| 交换C、Q的执行顺序，机械倒转前处理 | 部分行长度没有对应SBCC核心，新增内核目录和调度开销不必要 |
| 首段局部后处理后执行C+1行Q点FFT | 数学成立，但多一次Q点复数FFT，产生新尾块；端点合并方案已消除这项工作，不优先实施 |
| 强制线程重排，使列内配对都在线程束内 | 会改变普通FFT访存和核心交换，无法维持原工作组几何；留作另一次核心优化，不混入本次边界融合 |

若端点行确实导致严重寄存器退化，可把 `C+1` 行方案作为登记过的诊断对照；不能未经测量就按某个具体N切换方案。

## 八、前处理方案在EXP125上的必要调整

前处理数学仍采用此前已论证的方案，详见同目录的《前处理方案继承与起点差异》；它与本后处理方案不能仅靠反转方向共用整段代码。

- 前处理首段是 `Q+1` 次C点复数变换，额外一次C点FFT；本后处理首段只有Q次，不额外增加FFT。两方向开销需要分别记录。
- 前处理打包每行两个实数端点，中间矩阵同样保持 `C×Q`；末段做局部前处理后写实数。奇数C或奇数行槽使用有类型的标量分量写出，不能要求相邻复数槽永远对齐。
- 此前报告基于EXP127的81项分解结论不适用于EXP125。已核对两版SBCC／SBRC配置内容相同，因此可复用配置目录和数学证据；当前分解映射必须重新按EXP125核对。
- EXP125旧折叠入口没有后来补上的回调边界缓存。新候选需要独立实现唯一读取拥有者及C个复数的边界缓存；没有单次回调保证时，有回调的回退必须走未融合路径，不能直接挂接旧折叠入口并宣称已满足要求。
- 前处理同样需要奇数长度小表、真实物理空间分配和大相位合法基数选择。只移植窄坐标工具、访问器及新角色所需功能，不夹带EXP126／127的其他核心优化。

## 九、本轮证据及其边界

1. **起点。** 新分支的FFT目录树与EXP125标签完全一致；保留了分支创建记录和22个相关源码文件的校验值。该核对用于确认起点，不新增构建期间源码冻结或状态检查。
2. **数学和地址。** 独立实数FFT参考模型通过797例：279种合法目录组合的随机数据、459个小规模奇偶／退化边界用例、当前27项分解的54个脉冲／结构输入，以及旧五尺寸。最大相对无穷范数误差 `9.7528×10^-16`。同时检查N个实数各读一次、M+1个半谱频点各写一次、端点重打包的2Q个分量各读一次。
3. **回调顺序。** 模型使用非线性实数输入变换及不与共轭交换顺序的复数输出变换，339例负面对照能检出“先回调后共轭”的错误。这里检验的是数学和地址约定，尚未检验设备回调、缩放访问器及生成参数是否正确接入。
4. **目录覆盖。** 279种组合四种C／Q奇偶情况分别为96、117、29、37，最大N为2725888。EXP125默认映射中有27项通用大尺寸几何，另有四项 `N>65536` 的旧二次幂几何；64K仅作回归控制。目录合法不等于该尺寸默认计划已实际命中，必须由生成计划确认。
5. **最小编译。** 在服务器工具链 `dtk-26.04`、`gfx936`、优化三级、计算模式下，Q=125和128端点重打包原型编译成功；每个原型各两条8字节读取，无整数除法或间接调用。没有设备执行，没有完整FFT内核性能或寄存器证据。

本轮不检查此前排队任务的结果，不使用它们支持当前方案，也没有生成大规模参考数组备份。

## 十、实施后的最小验收

1. 先生成并编译全部合法配置的首末段代码，检查参数顺序、首末轮静态坐标、尾块掩码及共享峰值；代表配置检查汇编中的标量读取、溢出及寄存器数。普通复数生成结果不受新角色影响。
2. 正确性覆盖四种奇偶组合、首末块、奇数槽、部分首轮工作量、局部自配对点、零频及奈奎斯特频点；输入输出加保护区；回调计数与非交换输出变换、非单位缩放单独检查。误差采用项目既定严格 `<1e-9` 验收，数学模型误差不能替代它。
3. 实际融合证明同时记录计划、N、C、Q、工作组、入口和交换方式、相位周期、临时空间；执行仅包含两段变换，没有独立实数后处理或额外端点搬运。检查旧五尺寸候选未悄悄命中旧专用生成器。
4. 覆盖按列类、行类及资源／尾块类别登记，能找到五个合法 `N>65536` 时每类至少五个，包含较大尺寸。目录中列类50／52仅两项，60／64仅三项，72／80／81／84仅四项；行类49／50／64仅一项，81仅两项，100／112仅四项。应把这些类的全部可用组合测完并注明不足，不能把同一N多次测量冒充多个尺寸，或擅自声称五尺寸覆盖完成。
5. 正确性和实际融合通过后，使用统一入口、新计时程序的默认计划，每个尺寸／类型／版本一个进程，10次预热、30次正式测量；加速比只用中位数，保留逐次散点和序号图。比较双方相同分解，并保留官方及EXP125参考的真实含义。提交任务后停止，等用户要求检查。
6. 如果同一资源类系统性退化，先核对两轮交换、入口相位等待、末段分支寄存器及实际事务。按类型更改统一策略；不为单个N隐藏退化。新候选保持独立开关和安装记录，验收前不推广稳定版本。
