这里展示的是实际内核生成器代码。`Assign`、`If`、`LoadGlobal`、`StoreGlobal`等对象用于生成设备端计算、判断和读写语句。

## 先看流水结构

| 方向 | EXP125 | 第五版与第六版 |
|:---|:---|:---|
| z2d | 折叠列变换 → 行内前处理及行变换 | 打包折叠列变换 → 行内前处理及行变换 |
| d2z | 普通列变换 → 配对行变换及完整后处理 | 列变换及局部后处理 → 行端相位补偿、行变换、半谱写出和端点补全 |

因此，z2d保留了行内前处理的核心思路，布局和读写安排发生改变；d2z还重组了后处理所在阶段。

template <typename T> __device__ __forceinline__ void cc_pre_pair(T p, T q, T w, T& own, T& other)
{
    const auto ux = p.x + q.x, uy = p.y + q.y, vx = p.x - q.x, vy = p.y - q.y;
    const auto a = vx * w.y - uy * w.x, b = uy * w.y + vx * w.x;
