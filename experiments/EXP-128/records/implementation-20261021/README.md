# EXP128实施与验收登记

起点：`stable-main-exp125-20261007`，`77fd0040ab01aaeacd2cc6c30914185d9304adbd`；候选分支`exp-128-cc-local-real`。稳定分支和标签不变。生产源码未迁移EXP126／127融合实现。

## 前处理

首段按`2Q*a+b`读取折叠半谱，完成C点逆变换及N周期相位，读取列数为Q+1。第0列与第Q列的实部分别写入首个复数槽的两个分量；其他列正常写入C×Q矩阵。端点使用8字节存储，避免整槽覆盖。回调模式下，共轭配对的边界读取在工作组内共享：缓存复用首段核心共享区，全部寄存器加载完成后同步，再交还FFT核心，未增加共享存储容量。

末段在每个SBRC行内完成2Q实数逆变换前处理，再使用普通Q点逆FFT。可证明满足原生首轮寄存器映射时使用波内交换，否则走共享存储入口；两者均不更改普通蝶形核心。行输出按物理相邻且同组所有的实数打包写入，首尾不足一对时用标量写入。整个流程多做一次C点变换，中间矩阵仍为M个复数。

## 后处理

首段将相距Q的两个实数样本打包，使用普通C点FFT，在列内完成2C实数变换后处理。普通行输出局部半谱，端点行保留原始偶、奇求和两分量。末段普通行读取时乘N周期相位，执行Q点FFT，折叠到全局半谱并在写回调前共轭。端点行把两分量看作2Q个实数，重新按相邻样本打包，用一个Q点FFT和局部后处理产生全部端点频点。

普通变换数量、中间C×Q矩阵及核心共享容量不增加。原生核心使用半容量共享存储的列类型以实部、虚部分两轮交换实现局部配对；其他类型直接复用完整复数共享区。额外成本为局部配对算术、首段共享区交换与同步、末段折叠寻址、端点行重排以及小相位表。小表和末段大相位表在计划阶段生成，不进入事件计时窗口。

## 验收与性能

`coverage.json`登记193个公开默认尺寸、279种内部C／Q组合、33种列长度及20种范围内行长度；公开默认涉及其中17种行长度，不能把另外3种内部覆盖算作公开默认覆盖。最大N为2725888。部分类型在原生目录及N范围内不足五个组合，全部覆盖并保留实际数量。64K为旧路径回归。

每个公开尺寸验证两个方向的独立随机参考，覆盖全部默认分解。39个覆盖所有公开列／行类型的代表尺寸加测七类输入、1及0.375缩放、无回调／双回调／仅读取／仅写入回调，每项执行两次，检查输入不变、完整输出及保护区；回调逐物理元素恰好一次。复数写回调加入虚数偏移，检验共轭顺序。代表尺寸另使用原计时程序和分析器关联每次实际启动，要求候选每次仅有登记的两个新角色，禁止独立前后处理内核。

融合构建另用全部279种C／Q组合运行完整两段内部流水、两方向、双回调及0.375缩放，覆盖默认分解冲突、尾块、奇偶及端点，中间缓冲区也有保护区。内部强制几何仅用于正确性，绝不用于正式计时。

正式性能只测两版默认路径：386个尺寸／类型组合，772个独立进程，每进程10次预热、30次正式样本；中位数加速比、散点与序号图。未融合版关闭全部CC实数融合，候选启用新方案；分解补项相同，故收益包括新方案的全部附加开销。A100只作匹配项的跨设备参考。性能任务显式依赖两版构建及验证成功，任何一版失败均不开始计时。提交后停止，等待用户检查。

主机证据不表示设备验收通过，也不表示性能改善。候选通过后仍不自动升级稳定版。
