# EXP127：卷积路径前后处理融合，第一阶段登记

用户确认本轮先完成共用接口和卷积（Bluestein）两端融合，提交构建、正确性及实际融合验证后停止；转置（TRTRT）接入和正式性能另行推进。起点为稳定分支 main 的 `697f6f0a8a3ffa9dd255d911b488856722f4e839`，标签“完成CC路径前后处理融合”；独立分支 `exp-127-real-bluestein-boundary`。候选保持复数交换默认配置，不修改CC数学、生成器、分解表或既有安装。

## 接入与边界

只接入一维、双精度、批量一、非原位、单位步长、零偏移、偶数 N＞65536、设备 gfx936，且半长 M＝N／2 的默认复数计划实际为六段卷积（BT_MULTI_KERNEL）。单块卷积、其他方案表、精度、布局和不满足条件的计划沿用旧路径。选择按路径和合法资源判断，不按完整尺寸写优化分支。

共用边界描述保存完整N、方向、载体和布局版本；与局部FFT参数、设备指针分开。父节点只描述用户视图，指定末端叶节点持有旋转因子；不传播到卷积内部FFT。物理视图明确前处理读取 M＋1 个复数、后处理写出 M＋1 个复数。

z2d将前处理合入填零与啁啾相乘（PAD_MUL）；d2z将后处理合入结果提取（RES_MUL）。保留啁啾生成（CHIRP）、内部正变换批量二、频域相乘（FFT_MUL）、内部逆变换、原卷积长度L、各段分解以及三段L大小的缓冲布局。输入填零仍在原偏移2L，结果读取仍在2L。首个叶节点是啁啾生成，不能用它代替用户输入边界。

每个线程唯一负责 k、M−k 一对；零频和奈奎斯特频点由一个线程独占，M为偶数时另有一个自配对频点。M为奇数时，镜像啁啾只需对同一加载值取负；不重读第二个啁啾。填零任务独立，不读取用户输入、回调或系数。后处理的卷积归一化1／L只做一次，用户缩放由原写出操作统一执行。新路径无共享存储交换或块内同步；额外开销为镜像地址、少量分支、配对运算和四分之一N的旋转因子表，实际性能待设备验证后测量。

普通多段卷积同时补齐实数回调适配：d2z未融合的输入边界分别调用两次实数读取回调，z2d未融合的输出边界分别调用两次实数写出回调。删除生成器重复声明的缩放参数，启动端与写出访问器保持唯一一致；普通多段名称增加接口版本后缀，融合名称增加方向和布局后缀，避免旧缓存混用。单块卷积和啁啾接口不变。

## 默认路径覆盖

登记来源为源码计划模型，尚未证明设备实际选择；验证必须重新读取实际L和融合角色。走回退或归入其他类型的尺寸不能算作该类型覆盖。

| 类型 | 五个N |
| --- | --- |
| M偶数，L混合因子 | 65540、201840、371288、560372、681468 |
| M偶数，L为2的幂 | 117652、507752、776688、888376、999996 |
| M奇数，L混合因子 | 65538、201038、370546、559910、681470 |
| M奇数，L为2的幂 | 117654、507378、776406、888202、999998 |

20个N的z2d、d2z共40项；另加原五尺寸三方向15项、已有CC两方向6项、转置两方向10项、普通复数卷积3项，共74项基础检查。40项目标另用已保留稳定库检查数学及内部卷积计划一致性，不能将这些辅助计时作为正式性能结果。

目标按两个方向、无回调／有回调共80组。每组七种输入：首端脉冲、末端脉冲、常数、奈奎斯特、自配对／邻近频率、多频率、随机；各用1和0.375缩放，共1120项独立完整N点参考，每项同一计划执行两轮，共2240次。参考由完整N点数值计算（NumPy）产生；不同N、方向和回调的原始二进制分别保存，记录配方、种子、版本与校验值。

验证输出误差严格小于1e−9、全部有限、每个输出都写入、输入保持原值；输入、输出、工作区、回调计数和用户数据均有两端保护。回调须在正确用户地址恰好调用一次，越界计数为零；检查两次同参数计划创建、释放一个所有者、保留另一个执行及重复创建销毁。实际计划、运行编译源码和执行日志必须同时证明新角色已编译并执行，独立实数前后处理已消除，原三类卷积边界仍按预期次数执行，内部正反FFT的长度、批量、方向和分解与稳定版相同。

再检查批量二、非单位步长、偏移、原位、平面格式、多维、小尺寸、奇数N、单精度共18项范围回归。单精度只检查计划创建及未接入新角色；其余16项执行独立脉冲／常数参考和保护检查。不把范围回归算入实际融合覆盖。
