# EXP126：新增尺寸结果检查

**结论：正确性和实际融合通过；性能仍有类型差异，保留两候选，EXP125继续作为稳定版。**

检查日期为2026-10-13。复数构建908730、标量构建908731、复数性能909379、标量性能909381均正常完成，退出码为零。依赖按登记顺序生效，性能在两份验证完成后开始。两次性能测试在同一节点、同一显卡上先后运行，各自独占节点；两候选没有在同一次申请中交错测量。

每份65项基础检查、100组保护／回调／融合检查和1400组独立参考案例均通过，每组参考执行两轮。实际轨迹均为两段矩阵变换，独立前后处理已消除。默认后端、行列尺寸、线程数、共享容量及生成身份符合登记；前处理1024列、后处理1331行的标量交换确实命中。最大已记录误差为 4.59e-15，满足严格小于1e-9。

每份正式计时53项尺寸／类型组合：25个新增偶数长度的两个实数方向共50项，以及3项复数方向控制。其中24项是八类各三个目标成员，另外26项是关联实数方向或控制。每项有官方基线、EXP125稳定对照及一个候选，各一个进程、三次预热、五十次逐次同步的完整变换计时。共318个进程、15900个正式样本；未删除慢点。原五尺寸三类型的15项只做了基础正确性回归，本批未重测它们的性能。

逐进程计数、顺序、正确性、设备、库和原始文件校验值核对通过；中位数、分位数与加速比从原始样本独立重算，与运行记录一致。本文只用中位数分析；不将历史A100均值与当前中位数混算。
