# EXP125 后处理旋转因子访存修改

本轮在此前通过正确性验证的后处理融合代码上修改，继续使用半长复数变换。适用范围仍为六万四千至一百万点、双精度、单批次、输入输出分离。没有引入此前失败的前处理实现。

旋转因子表按线程块及线程的实际读取顺序生成。每个线程块的一段表连续排列，线程读取自身位置及后续轮次对应的位置。表仍包含原来的四分之一长度，角度及正弦、余弦计算不变；生成时直接写到新位置，不增加临时表或重排步骤。

普通路径在傅里叶变换结束后的同步处，提前读取后处理需要的两项或四项旋转因子。回调路径逐轮读取，控制寄存器同时存活的数量。两种加载方式均使用相同的新表。

表缓存沿用现有的设备隔离、引用计数和释放机制，增加行长度及每个线程块处理行数两个布局字段，避免与普通表混用。生成表时从实际核函数元数据取得行数。新核函数名称区分表布局及读取方式。

修改涉及九个源码文件：

| 文件 | 修改 |
| --- | --- |
| `device/generator/stockham_gen_real_post.h` | 连续表读取；普通路径提前读取；回调路径逐轮读取 |
| `rtc_stockham_gen.cpp` | 生成时选择读取策略；更新新路径的核函数名称 |
| `tree_node.cpp` | 从核函数元数据取行数，申请新表 |
| `include/repo.h`、`repo.cpp` | 增加布局缓存字段及申请接口 |
| `include/twiddles.h`、`twiddles.cpp` | 新表分配、生成、同步及精度分派 |
| `include/rtc_twiddle_gen.h`、`rtc_twiddle_gen.cpp` | 增加直接生成新布局的旋转因子核函数 |

额外开销为建表时的整数索引运算、缓存键两个字段，以及普通路径提前读取时暂存的旋转因子。表的设备空间不增加。如果普通计划和融合计划同时存在，两种表会分别保留。共享存储、启动规模、输入中间矩阵、后处理配对公式及输出位置保持原样。
