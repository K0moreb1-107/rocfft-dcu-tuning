========== Interpretation ==========
1) P-State/clocks are snapshots. Low idle clocks or an Idle clock-event reason alone are not proof of a benchmark problem.
2) CPU quotas and nr_throttled/throttled_usec can indicate possible host-side launch/synchronization contention, not GPU kernel slowdown by themselves.
3) nvidia-smi driver CUDA Version is an upper supported version, not the installed nvcc Toolkit version.
4) Container visibility of GPU power/clock controls can be incomplete; a missing field does not mean the feature is disabled.
5) This report only reads state once; it cannot establish whether clocks, power, or neighbors changed during FFT timing.
